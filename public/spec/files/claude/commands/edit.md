Load the `edit` skill and follow it. Read `config.json` `editor` first: `none` means you
edit alone with ffmpeg (the `assemble` skill); any program means you edit in it, using its
MCP and computer use together, and you ask before taking over the screen. Verify every
block has a clip before editing. Never add music.
